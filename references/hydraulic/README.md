# Hydraulic dataset reference

## Source record

This study uses the UCI Machine Learning Repository dataset [Condition monitoring of hydraulic systems](https://archive.ics.uci.edu/dataset/447/condition%2Bmonitoring%2Bof%2Bhydraulic%2Bsystems), dataset 447.

- Dataset DOI: [10.24432/C5CW21](https://doi.org/10.24432/C5CW21)
- Dataset creators listed by UCI: Nikolai Helwig, Eliseo Pignanelli, and Andreas Schütze
- Local source files: [`data/hydraulic/raw/`](../../data/hydraulic/raw/)
- Local metadata: [`description.txt`](../../data/hydraulic/raw/description.txt) and [`documentation.txt`](../../data/hydraulic/raw/documentation.txt)

The dataset was obtained from a hydraulic test rig that repeats 60-second constant-load cycles. It contains raw multivariate time-series measurements and cycle-level values in `profile.txt`. The UCI record reports 2,205 instances and 43,680 features.

## Citation

Use the following citation for the dataset:
